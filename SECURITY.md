# Security reporting

Use this page to report a JobScout issue. Read [the JobScout security policy](agents/SECURITY.md) for supported versions and security limits.

[Report privately](#report-privately) · [Scope](#scope)

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/mlohmann/ai-skills/security/advisories/new) if it is available. Include steps to reproduce the issue with synthetic data.

Don't post secrets, personal profiles, or exploit details in public issues. If private reporting is unavailable, open an issue to request a private channel. Leave out confidential data and exploit details.

## Scope

The JobScout review covers files under `agents/` and its repository discovery entries. It does not certify or promise security support for other repository content.
