# Security reporting

For JobScout under `agents/`, see [the JobScout security policy](agents/SECURITY.md).

Use [private vulnerability reporting](https://github.com/mlohmann/ai-skills/security/advisories/new) when available. Report with synthetic data and a minimal reproduction. Do not disclose secrets, personal profiles or exploit details in public issues. If private reporting is unavailable, request a private channel in a sanitized issue.

Other repository content has not been included in the JobScout security review and has no implied support or security certification from it.
