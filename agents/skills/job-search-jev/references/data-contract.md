# Helper data contract

Python 3.9+ standard library only. Commands print JSON to stdout; they do not browse or call JEV.

`request PROFILE JOB` creates JEV tool arguments. `rank PROFILE JOBS HISTORY` ranks normalized evidence. JOBS and HISTORY are JSON arrays. Each job has company, requisition_id (or employer_url), title, location; eligibility gates role_eligible, seniority_eligible, location_eligible, work_model_eligible are booleans or null. Also active and employer_verified are booleans/null. employer_url is the verified canonical employer link, not an aggregator. Unknown verification is never a pass. `conflicts` is an array of unresolved evidence conflicts. `posted_at` is ISO date or null. Optional `salary`: {min,max,currency,period,employer_reported}, with annual base amounts. Optional `evaluation`: {provider:"jev"|"assistant", scores:{criterion_id:0..100}, confidence:0..1|null, raw_response:...}. Set provider only from actual execution provenance. Assistant fallback is reviewed manually, not automatically verified by this helper.

History entries: {company,requisition_id,employer_url,status}. An empty history array means the user checked and supplied no history; omitted/null history means not checked. Only exact strong identities exclude; weak identities always require review. Duplicate normalized jobs retain the first entry and flag conflicts for agent consolidation rather than claiming automatic evidence reconciliation. Output buckets: shortlist (top_n), qualified (all), review, excluded, below_threshold. Reasons are audit codes, not model explanations. Runtime profiles and outputs belong outside the repository.
